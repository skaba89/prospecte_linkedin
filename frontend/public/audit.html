Audit & compliance (P21 + P48/P52) — trace immuable des actions mutantes du tenant (qui a fait quoi, quand, depuis quelle IP). Inclut les actions CRM (crm.contact.create), webhooks (webhook.create, inbound.contact_created), approbations, séquences, membres (member.invite, member.role_change), SSO Enterprise (sso.config.upsert, sso.config.delete — P48) et facturation (billing.plan.change, billing.currency.change — P48). Filtrage par préfixe d'action, acteur, type de cible, plage de dates, IP source (P52 SOC2). Export CSV pour conformité.
P53 compliance-grade : alertes (burst IP > 10/h = brute-force suspect, actions système/anonymes), purge rétention (rétention 7 ans SOC2, loggée meta audit.purge), export PDF signé HMAC-SHA256 (non-répudiation tamper-evident).
P55 webhook alerts : config webhook Slack/email + seuil min_severity + notify push (POST alertes vers webhook) + cron hebdo (purge + notify auto).
