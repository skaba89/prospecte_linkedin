RevPulse Webhooks Inbound

← Dashboard CRM Webhooks sortants
Webhooks inbound (P20) — un système externe (formulaire site, Zapier, CRM) POST un payload JSON sur l'URL publique ci-dessous → RevPulse crée ou met à jour un Contact (dédup par email puis linkedin_url). Pour les nouveaux contacts, l'événement contact.created est émis → déclenche les webhooks sortants (P18) : la chaîne in→out est complète. Champs mappables par défaut : first_name, last_name, email, phone, title, linkedin_url.

Endpoints inbound

Créer un endpoint inbound

Le token (32 hex) est auto-généré + retourné une fois — copie-le dans la config du système source. Un endpoint inactif retourne 410 Gone.

Tester l'endpoint

POST un payload JSON de test sur l'URL publique (sans auth — le token authentifie). Le contact créé/mis à jour apparaîtra dans le CRM.
