📥 Portabilité — Exporter mes données (Art. 20)

Télécharge un bundle JSON de toutes vos données personnelles (profil, contacts détenus, historique d'audit déclenché, profil career, candidatures). Machine-readable — vous pouvez réimporter ailleurs.

✅ Consentement (Art. 7)

Gérez vos consentements par finalité. Consentement explicite requis (Art. 7) + retrait à tout moment (Art. 7.3). Chaque grant/withdraw est tracé (IP, UA, version privacy policy) — preuve DPO.

🗑 Effacement — Right to be forgotten (Art. 17)

Anonymise vos données personnelles (nom, email, contacts PII, audit actor_name scrubbed). Les enregistrements structurels sont conservés (FK integrity + rétention SOC2 7 ans — GDPR Art. 17.3.b/e). Action irréversible — vos données seront anonymisées définitivement.
